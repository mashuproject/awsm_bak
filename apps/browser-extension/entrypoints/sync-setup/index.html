Re-encrypt synchronized Vault

This creates a cryptographically independent Vault, replaces every reachable identifier and encrypted record, removes every other Device, and schedules the old synchronized copy for deletion without a server Recovery Snapshot.

  • The operation may require substantial time and temporary local storage.
  • Other Devices must enroll again using the new Recovery Phrase.
  • Copies already downloaded or exported elsewhere cannot be erased.
  • A newly verified Complete Export is mandatory.

Save the replacement Recovery Phrase

After activation, this is the only Recovery Phrase that can enroll Devices into the replacement Vault. The old phrase will no longer be accepted.
